⚠ Chưa cấu hình

Trang này chưa được nối với Google Sheet của bạn. Mở file index.html, tìm dòng cấu hình gần đầu thẻ <script>:

const CONFIG = {
  WEB_APP_URL: "https://script.google.com/macros/s/AKfycby-q3w8y1tszDfPIp3x_n3BvYpD2GcWHHQHoCrQCHCjmM_RUENJvwiBVUqZbtln_rMkOQ/exec",   // ← dán URL Apps Script Web App (kết thúc bằng /exec)
  LEAD_DAYS: 7
};

Dán URL Web App (kết thúc bằng /exec) bạn lấy được sau khi Deploy Apps Script vào giữa hai dấu ngoặc kép, lưu file rồi tải lại trang. Xem file HUONG_DAN_TRIEN_KHAI.md để có các bước đầy đủ.
